# v0.9.1 — `/me/analyses` N+1 fix + Layer A cache schema version Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two tiny perf patches batched per the 2026-05-26 v0.9.x decomposition: (1) eliminate the per-row `SELECT AnalysisRun` in `/me/analyses` by surfacing the already-joined tuple from `list_user_analyses`; (2) add a `REPORT_SCHEMA_VERSION` constant to the Layer A cache key so future `Report`-shape changes can invalidate the report namespace without nuking other caches.

**Architecture:** `list_user_analyses` already joins `aliased(AnalysisRun)` via `latest_run_id` but discards the join result. Patch 1 just stops discarding it — return type becomes `tuple[list[tuple[Analysis, AnalysisRun | None]], int]`, and the route consumes the tuple directly. Patch 2 adds `REPORT_SCHEMA_VERSION = 1` in `app/cache/keys.py`; `report_key(username)` returns `f"v{REPORT_SCHEMA_VERSION}:{username.lower()}"`. Final composed key: `si:v1:report:v1:octocat`.

**Tech Stack:** Python 3.12, SQLAlchemy 2.0 async, pytest, ruff, uv.

**Spec:** [`docs/superpowers/specs/2026-05-27-v0.9.1-perf-batch-design.md`](../specs/2026-05-27-v0.9.1-perf-batch-design.md).

**Branch:** `feat/v0.9.1-perf-batch` (already created, spec already committed as `de5b32e`).

**TDD shape:** Patch 2 (cache) is pure-unit, lands first. Patch 1 (N+1) is mostly type-driven; tests sit on the existing DB-fixture path. Task 3 catches any ruff drift. Task 4 ships.

```python
async def list_user_analyses(
    db: AsyncSession,
    *,
    user_id: int,
    sort: Sort = "recent",
    page: int = 1,
    page_size: int = 20,
) -> tuple[list[tuple[Analysis, AnalysisRun | None]], int]:
    """Return (rows, total). 1-indexed pages.

    Each row is `(analysis, latest_run)` — the join is computed once at the
    DB level so the caller doesn't need to round-trip per row (v0.9.1: closes
    the /me/analyses N+1).
    """
    latest = aliased(AnalysisRun)
    base = (
        select(Analysis, latest)
        .where(Analysis.user_id == user_id)
        .join(latest, Analysis.latest_run_id == latest.id, isouter=True)
    )
    if sort == "recent":
        base = base.order_by(desc(latest.ingestion_completed_at))
    elif sort == "score_desc":
        base = base.order_by(desc(latest.total_score))
    elif sort == "score_asc":
        base = base.order_by(latest.total_score)

    total = await db.scalar(
        select(func.count()).select_from(Analysis).where(Analysis.user_id == user_id)
    )

    offset = max(0, (page - 1) * page_size)
    result = (await db.execute(base.offset(offset).limit(page_size))).all()
    return [(row[0], row[1]) for row in result], int(total or 0)
```
