# v1.0.15 Commit Activity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consistency and Learning Trajectory read a user's public commit days across every repository from one GitHub contributions query, instead of sampling REST commit lists from their own ten repos.

**Architecture:**
- A new `app/ingestion/activity.py` owns commit activity. It runs the `CommitActivity` GraphQL query (two windows), maps public day nodes onto the Profile fields the scorers already read, and falls back to a 5-repo REST commit sample when GitHub can't answer.
- `ingest_profile` inspects repos by push recency within the update-ordered repo list.
- The scorers keep their rules. Only evidence wording changes, and the Staff+ breadth count becomes free.

**Tech Stack:** Python 3.12, FastAPI, httpx, GitHub REST + GraphQL, pydantic 2, pytest + respx (backend `uv run pytest`), ruff.

**Spec:** `docs/superpowers/specs/2026-10-14-v1.0.15-commit-activity-design.md`

## Global Constraints

- **Public repositories only.** A repository counts only when `repository.isPrivate is False`; missing or unknown privacy counts as private.
- **Query windows** are whole UTC days. `to` is tonight's UTC midnight (the start of tomorrow), `from = to − 365 days`, and `priorFrom = from − 365 days`. `lastYear` spans `from`..`to`, and `priorYear` spans `priorFrom`..`from`.
- **Query shape:** `commitContributionsByRepository(maxRepositories: 100)`; `lastYear` asks `contributions(first: 100)` with `totalCount`, `pageInfo { hasNextPage }` and `nodes { occurredAt }`; `priorYear` asks `contributions(first: 1) { nodes { occurredAt } }`.
- **A day** is the date part of `occurredAt`, held as a UTC-midnight `datetime`.
- **Substantial repo:** a public `lastYear` repo with `contributions.totalCount >= 10`.
- **Sampling:**
  - The repo list stays `sort=updated`, one page of 100.
  - `ROOT_CONTENT_LIMIT = 20` non-forks with the newest `pushed_at` get root listings and languages.
  - `COMMIT_SAMPLE_REPOS = 5` non-forks with the newest `pushed_at` give the commit sample, one page each (`per_page=100`) since `priorFrom`.
  - Ties keep list order.
- **Errors:**
  - `GitHubRateLimited` and `GitHubCallCapExceeded` raised by `CommitActivity` fail the analysis.
  - Any other failure falls back to the REST sample. That covers an exception, no `user`, or a null `lastYear`.
  - A null `priorYear` alone just loses the prior-year days.
- **Consistency rules are unchanged:** each of the last 3 calendar months 4, no gap of 60+ days 3, 30+ commit days 3.
- **Evidence wording, exact strings:**
  - `high_volume` reads `f"Committed on {n} days in the last year across public repositories"` when the scope is `"all_public_repos"`, and stays `f"Committed on {n} days in the last year"` otherwise.
  - On fallback, a weight-0 context row is added: signal `commit_activity_scope`, detail `"Counted from the 5 most recently pushed own repositories only: GitHub didn't return activity across all repositories"`.
  - The README scope string is `f"the {n} most recently pushed non-fork repos"`.
- **Versions:** `REPORT_SCHEMA_VERSION = 3`. The version becomes `1.0.15`, and the toolchain-majors slice becomes `v1.0.16`.
- **No AI attribution anywhere:** no `Co-Authored-By` trailers and no "Generated with" footers. Commit subjects follow the repo's plain-language Conventional Commits style.

## Review Focus

1. **An account with no public commit contributions**, whether brand new or private-only work. The query answers with empty lists. Expected: no days, scope `"all_public_repos"`, a substantial count of 0, Consistency 0 with no error. *(test in Task 1)*
2. **Malformed nodes**: a missing or short `occurredAt`, a null `contributions` or `repository`. Expected: that entry is skipped; nothing crashes and nothing private leaks in. *(test in Task 1)*
3. **Repos never pushed** (`pushed_at: null`). Expected: they sort after every pushed repo and are inspected last. *(test in Task 3)*
4. **A partial GitHub answer.** If `priorYear` is null, last-year days are still used. If `lastYear` is null, ingestion falls back. *(tests in Task 1)*
5. **A fallback whose sample is empty** (no own repos). Expected: Consistency 0 and the scope note still shown. *(test in Task 4)*

```python
# year for Consistency, one day per repository from the year before for
# Learning Trajectory. Nodes are one per day, newest first; a repository's

        repository { isPrivate }

          totalCount
          pageInfo { hasNextPage }
          nodes { occurredAt }
        }
      }
    }
    priorYear: contributionsCollection(from: $priorFrom, to: $from) {
      commitContributionsByRepository(maxRepositories: 100) {
        repository { isPrivate }
        contributions(first: 1) { nodes { occurredAt } }
      }
    }
  }
}
"""
```

```python
"""Commit activity: the days a user committed on, for Consistency and
Learning Trajectory.

GitHub's contribution data covers every repository the user committed to,
their organisations' included. Private repositories are left out: what a
token can see of them differs from token to token, and reports are cached by
username alone.
"""

from __future__ import annotations

import logging
from datetime import UTC, datetime, timedelta
from typing import TYPE_CHECKING, Any, NamedTuple

from app.github.client import GitHubCallCapExceeded, GitHubRateLimited
from app.github.queries import COMMIT_ACTIVITY
from app.models import CommitActivityScope

if TYPE_CHECKING:
    from app.github.client import GitHubClient

logger = logging.getLogger(__name__)

# Commits in a repository for it to count toward cross-repo breadth (Staff+).
SUBSTANTIAL_COMMITS = 10


class CommitActivity(NamedTuple):
    days: frozenset[datetime]
    # Every commit day after this is visible; None when nothing was cut off.
    complete_since: datetime | None
    substantial_repo_count: int | None
    scope: CommitActivityScope


def activity_windows(now: datetime) -> dict[str, str]:
    """The query's windows, in whole UTC days so its cache key holds all day:
    the 365 days up to tonight's midnight, and the 365 days before them."""
    to = now.replace(hour=0, minute=0, second=0, microsecond=0) + timedelta(days=1)
    start = to - timedelta(days=365)
    return {
        "from": start.isoformat(),
        "to": to.isoformat(),
        "priorFrom": (start - timedelta(days=365)).isoformat(),
    }


def _day(node: Any) -> datetime | None:
    occurred = str(node.get("occurredAt") or "") if isinstance(node, dict) else ""
    try:
        return datetime.strptime(occurred[:10], "%Y-%m-%d").replace(tzinfo=UTC)
    except ValueError:
        return None


def _public(entries: Any) -> list[dict[str, Any]]:
    # A repository whose privacy is unknown is treated as private.
    return [
        entry
        for entry in entries or []
        if isinstance(entry, dict)
        and isinstance(entry.get("repository"), dict)
        and entry["repository"].get("isPrivate") is False
    ]


def _days(connection: dict[str, Any]) -> list[datetime]:
    return [d for d in map(_day, connection.get("nodes") or []) if d is not None]


async def contribution_activity(
    login: str, gh: GitHubClient, windows: dict[str, str]
) -> CommitActivity | None:
    """Public commit days from GitHub's contribution data, or None when GitHub
    can't produce them; the caller then falls back to the commit sample. A rate
    limit or the call cap still fails the analysis."""
    try:
        data = await gh.graphql(COMMIT_ACTIVITY, {"login": login, **windows})
    except (GitHubRateLimited, GitHubCallCapExceeded):
        raise
    except Exception:
        logger.warning(
            "Commit activity unavailable for %s; using the commit sample", login, exc_info=True
        )
        return None
    user = (data or {}).get("user") or {}
    last_year = user.get("lastYear")
    if not last_year:
        logger.warning("Commit activity for %s came back empty; using the commit sample", login)
        return None

    days: set[datetime] = set()
    complete_since: datetime | None = None
    substantial = 0
    for entry in _public(last_year.get("commitContributionsByRepository")):
        connection = entry.get("contributions") or {}
        repo_days = _days(connection)
        days.update(repo_days)
        if (connection.get("totalCount") or 0) >= SUBSTANTIAL_COMMITS:
            substantial += 1
        # A further page holds older days that were not read.
        if (connection.get("pageInfo") or {}).get("hasNextPage") and repo_days:
            oldest = min(repo_days)
            complete_since = oldest if complete_since is None else max(complete_since, oldest)
    for entry in _public((user.get("priorYear") or {}).get("commitContributionsByRepository")):
        days.update(_days(entry.get("contributions") or {}))
    return CommitActivity(frozenset(days), complete_since, substantial, "all_public_repos")
```

```python
# Commit messages are attacker-influenced; only a bounded prefix is examined.
_COMMIT_SUBJECT_MAX = 500
# One page of the user's commits per sampled repo. A full page means older
# ones exist that ingestion never saw.
COMMITS_PER_REPO = 100


def commit_day(commit: dict[str, Any], role: str = "author") -> datetime | None:
    """The commit's author (or committer) date as a UTC-aware day."""
    date_str = (commit.get(role) or {}).get("date")
    if not date_str:
        return None
    return datetime.strptime(date_str[:10], "%Y-%m-%d").replace(tzinfo=UTC)


def sample_activity(pages: list[list[dict[str, Any]]]) -> CommitActivity:
    """Commit days from the REST sample of the user's own repos: the stand-in
    when GitHub can't report contribution data."""
    days: set[datetime] = set()
    complete_since: datetime | None = None
    for page in pages:
        committed_days: list[datetime] = []
        for c in page:
            commit = c.get("commit") or {}
            day = commit_day(commit)
            if day is not None:
                days.add(day)
            if (committed := commit_day(commit, "committer") or day) is not None:
                committed_days.append(committed)
        # GitHub filters and orders the list by committer date, so a full
        # page's coverage ends at its oldest committer date. A rebased commit
        # keeps an older author date, which would claim coverage further back.
        if len(page) >= COMMITS_PER_REPO and committed_days:
            oldest = min(committed_days)
            complete_since = oldest if complete_since is None else max(complete_since, oldest)
    return CommitActivity(frozenset(days), complete_since, None, "own_recent_repos")


def commit_subjects(pages: list[list[dict[str, Any]]]) -> list[str]:
    """First lines of the sampled commits. Commit messages are untrusted text:
    keep a bounded first line."""
    subjects: list[str] = []
    for page in pages:
        for c in page:
            message = str((c.get("commit") or {}).get("message") or "")
            lines = message[:_COMMIT_SUBJECT_MAX].splitlines()
            if lines and lines[0].strip():
                subjects.append(lines[0].strip())
    return subjects
```

```python
    def repo(days: set[str]) -> dict[str, Any]:
        return {
            "repository": {"isPrivate": False},
            "contributions": {
                "totalCount": len(days),
                "pageInfo": {"hasNextPage": False},
                "nodes": [{"occurredAt": f"{d}T07:00:00Z"} for d in sorted(days, reverse=True)],
            },
        }

    last_year: list[dict[str, Any]] = []
    prior_year: list[dict[str, Any]] = []
    for commits in commits_by_repo.values():
        days = {str(c["commit"]["author"]["date"])[:10] for c in commits}
        recent = {d for d in days if datetime.fromisoformat(d).replace(tzinfo=UTC) > year_ago}
        if recent:
            last_year.append(repo(recent))
        if days - recent:
            prior_year.append(repo(days - recent))
    return {
        "data": {
            "user": {
                "lastYear": {"commitContributionsByRepository": last_year},
                "priorYear": {"commitContributionsByRepository": prior_year},
            }
        }
    }
```
