# v1.0.6 Shared-Token Quota Breaker — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven-development) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Shed new anonymous analyses (503) before the shared GitHub token's hourly quota is fully exhausted, so the platform degrades gracefully instead of hard-failing all anon analyses. Deferred extension of audit SI-03.

**Architecture:** `GitHubClient` observes `X-RateLimit-Remaining` on live shared-token responses and writes a low-water mark to Redis (only when it dips below a watch threshold). `_live_ingest` reads that mark and sheds new anonymous analyses when the reserve is gone. Signed-in users (own token) bypass. Ships as **v1.0.6**.

**Tech Stack:** FastAPI, `httpx`, `upstash_redis`, `pytest`/`pytest-asyncio` (`asyncio_mode=auto`), `respx`, `uv`, `ruff`.

# v1.0.6: only track the shared token's remaining quota once it dips below this,
# so normal high-quota traffic writes nothing.
_SHARED_QUOTA_WATCH = 1000


async def record_shared_quota(cache: RedisCache, remaining: int) -> None:
    """Best-effort write of the shared token's low-water remaining quota."""
    try:
        await cache.set_json(
            NAMESPACE_GH,
            GH_SHARED_QUOTA_KEY,
            {"remaining": remaining},
            ttl_seconds=TTL_SHARED_QUOTA_SECONDS,
        )
    except Exception:
        logger.warning("failed to record shared GitHub quota", exc_info=True)


async def shared_token_quota_ok(cache: "RedisCache | None", *, min_remaining: int) -> bool:
    """True when it's safe to start a new shared-token analysis. Fail-open when
    the cache is unavailable or no low-water mark exists (quota is high)."""
    if cache is None:
        return True
    data = await cache.get_json(NAMESPACE_GH, GH_SHARED_QUOTA_KEY)
    if not data:
        return True
    return int(data.get("remaining", min_remaining)) >= min_remaining
```

Add the constructor param (alongside `max_calls`):

```
and store it: `self._is_shared_token = is_shared_token` (next to `self._max_calls`).

In `_request`, after `assert resp is not None`, add:
```python
        # v1.0.6: record the shared token's remaining quota when it dips low, so
        # the breaker can shed new anon analyses before exhaustion. Only writes
        # below the watch threshold — high-quota traffic is free.
        if self._is_shared_token and self._cache is not None:
            remaining = resp.headers.get("X-RateLimit-Remaining")
            if remaining is not None:
                try:
                    rem = int(remaining)
                except ValueError:
                    rem = None
                if rem is not None and rem < _SHARED_QUOTA_WATCH:
                    await record_shared_quota(self._cache, rem)
```
