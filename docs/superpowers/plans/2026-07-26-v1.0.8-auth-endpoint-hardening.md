**Files:** `backend/app/auth/sessions.py`; test `backend/tests/auth/test_sessions.py` (DB-fixture).
- Add test: after `create_session`, `select(Session).where(Session.id == sid)` is **None** (raw not stored) but the stored row's id equals `hashlib.sha256(sid.encode()).hexdigest()`; `get_session_with_token(sid)` still resolves; a random sid → None. Run → fail.
- Add `import hashlib` + `def _hash_session_id(sid: str) -> str: return hashlib.sha256(sid.encode("utf-8")).hexdigest()`.

### Task 2 — SI-16: Origin check on mutations
**Files:** `backend/app/auth/dependencies.py`; `backend/app/routers/analyses.py`, `backend/app/routers/refresh.py`; test `backend/tests/auth/test_dependencies.py` + a router test.
- Add test: `require_trusted_origin` with no Origin → passes; allowed origin → passes; foreign origin → `HTTPException(403)`; a `cors_allow_origin_regex`-matched origin → passes. Run → fail.
- Implement in `dependencies.py`:
```python
import re
from app import settings as settings_module

def _origin_allowed(origin: str) -> bool:
    s = settings_module.settings
    allowed = {o.strip() for o in s.cors_allow_origins.split(",") if o.strip()}
    if origin in allowed:
        return True
    rx = s.cors_allow_origin_regex
    return bool(rx and re.fullmatch(rx, origin))

def require_trusted_origin(request: Request) -> None:
    origin = request.headers.get("origin")
    if origin is None or _origin_allowed(origin):
        return
    raise HTTPException(status_code=403, detail={"error": "bad_origin"})
```
- Wire `_o: Annotated[None, Depends(require_trusted_origin)]` onto `POST /analyses/{id}/share`, `DELETE /analyses/{id}/share`, `DELETE /analyses/{id}`, and the `POST /me/refresh/{username}` handler in `refresh.py`.
- Router test: a `DELETE /analyses/1` with `Origin: https://evil.com` (+ a valid session override) → 403 `bad_origin`. Run → pass. Lint. Commit: `fix(analyses): reject state-changing mutations from an untrusted Origin (SI-16)`.
