# v0.6.0 — GitHub Receipts™ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one canonical dark 1200×630 PNG card per analysis, served via Next.js `next/og`, auto-wired into OpenGraph + Twitter meta tags, with a dedicated preview/download page reached from inline buttons on both `/u/[username]` and `/share/[slug]`.

**Architecture:** Next.js 16 file-convention `opengraph-image.tsx` at `/u/[username]/` and `/share/[slug]/`. Each route exports an async default function returning `new ImageResponse(<OgCard report={...} />, {...})`. The convention auto-injects the matching `<meta property="og:image">` and `<meta name="twitter:image">` tags into the page head; no manual meta wiring needed. The card content is a pure function of the Pydantic `Report` shape — deterministic, edge-cacheable, snapshot-testable.

**Tech Stack:** Next.js 16 App Router · React 19 · `next/og` (satori) · Tailwind 4 · vitest + happy-dom (new test framework — added in Task 1) · TypeScript 5.

**Spec:** [`docs/superpowers/specs/2026-05-19-v0.6.0-receipts-design.md`](../specs/2026-05-19-v0.6.0-receipts-design.md).

**Conventions over manual routes:** The spec described `/u/[username]/og.png` and `/share/[slug]/og.png` URLs. We use Next 16's file convention instead (`opengraph-image.tsx` → served at `/u/[username]/opengraph-image`). The convention auto-injects meta tags AND serves the PNG, so we don't need to write the meta tags ourselves. URLs differ from the spec; functionality is identical.

**Auth simplification:** The spec discussed "auth-aware" image routes (owner-only for private analyses). Re-reading the v0.5.0 surface, analyses are anonymously computable via `/analyze/{user}` — only the `/me` saved-history list is private. Both OG image routes call public endpoints (`/analyze/{user}` and `/share/{slug}`), no cookies. This matches what a social-platform crawler can actually fetch when it has no session.

```ts
import type { Report } from "@/types";

function backend(): string {
  return process.env.NEXT_PUBLIC_BACKEND_URL ?? "http://localhost:8000";
}

export async function fetchOgReport(username: string): Promise<Report | null> {
  try {
    const r = await fetch(`${backend()}/analyze/${username}`, { cache: "no-store" });
    if (!r.ok) return null;
    return (await r.json()) as Report;
  } catch {
    return null;
  }
}

export async function fetchOgReportBySlug(slug: string): Promise<Report | null> {
  try {
    const r = await fetch(`${backend()}/share/${slug}`, { cache: "no-store" });
    if (!r.ok) return null;
    const body = (await r.json()) as { report: Report };
    return body.report;
  } catch {
    return null;
  }
}
```

```tsx
export const alt = "Skill Issue · GitHub engineering scorecard";

// 5min edge cache; allow stale for a day.
export const revalidate = 300;

interface Params {
  params: Promise<{ username: string }>;
}

async function loadFonts() {
  const root = join(process.cwd(), "assets");
  const [regular, bold] = await Promise.all([
    readFile(join(root, "Inter-Regular.ttf")),
    readFile(join(root, "Inter-Bold.ttf")),
```

```tsx
"use client";

import { Check, Copy, Download, Link2 } from "lucide-react";
import { useState } from "react";

interface Props {
  imageUrl: string;
  shareUrl: string;
  downloadName?: string;
}

export function CardActions({ imageUrl, shareUrl, downloadName = "skill-issue-card.png" }: Props) {
  const [toast, setToast] = useState<string | null>(null);

  function flash(msg: string) {
    setToast(msg);
    setTimeout(() => setToast(null), 2500);
  }

  async function copyPng() {
    try {
      const r = await fetch(imageUrl);
      const blob = await r.blob();
      if (!("write" in navigator.clipboard) || !window.ClipboardItem) {
        throw new Error("clipboard.write unsupported");
      }
      await navigator.clipboard.write([new ClipboardItem({ "image/png": blob })]);
      flash("Card copied to clipboard");
    } catch {
      flash("Copy unsupported — use Download instead");
    }
  }

  async function copyUrl() {
    try {
      await navigator.clipboard.writeText(shareUrl);
      flash("URL copied");
    } catch {
      flash("Copy failed");
    }
  }

  return (
    <div className="flex flex-wrap items-center gap-3">
      <button
        type="button"
        onClick={copyPng}
        className="inline-flex items-center gap-2 rounded-full bg-card/60 border border-border px-4 py-2 text-xs font-medium hover:bg-card/80 transition-colors"
      >
        <Copy className="size-3.5" aria-hidden="true" />
        Copy PNG
      </button>
      <a
        href={imageUrl}
        download={downloadName}
        className="inline-flex items-center gap-2 rounded-full bg-card/60 border border-border px-4 py-2 text-xs font-medium hover:bg-card/80 transition-colors"
      >
        <Download className="size-3.5" aria-hidden="true" />
        Download PNG
      </a>
      <button
        type="button"
        onClick={copyUrl}
        className="inline-flex items-center gap-2 rounded-full bg-card/60 border border-border px-4 py-2 text-xs font-medium hover:bg-card/80 transition-colors"
      >
        <Link2 className="size-3.5" aria-hidden="true" />
        Copy URL
      </button>
      {toast ? (
        <span className="inline-flex items-center gap-1 text-xs text-emerald-300 ml-2">
          <Check className="size-3.5" aria-hidden="true" />
          {toast}
        </span>
      ) : null}
    </div>
  );
}
```
