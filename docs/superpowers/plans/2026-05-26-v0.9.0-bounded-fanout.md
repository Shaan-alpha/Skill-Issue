# v0.9.0 — Bounded GitHub Fan-out Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cap concurrent GitHub API calls inside `ingest_profile` to `settings.gh_ingest_concurrency` (default 8) so a single analysis can't burst past the per-token rate-limit budget and so anonymous-token sharing scales to more analyses/hr before the 5000/hr GitHub ceiling bites.

**Architecture:** A new file-local `_gated(sem, coro)` helper wraps any coroutine in `async with sem`. `ingest_profile` constructs one `asyncio.Semaphore(settings.gh_ingest_concurrency)` per call and reuses it across both `asyncio.gather` blocks. A new `Settings.gh_ingest_concurrency: int = 8` field (env override `GH_INGEST_CONCURRENCY`) makes the cap tunable in prod without redeploy. The sequential `list_languages` loop is left alone (already bounded by construction; parallelizing it would *increase* peak concurrent for the same cost — counter to the slice's goal).

**Tech Stack:** Python 3.12, `asyncio`, `pydantic-settings`, `pytest` + `pytest-asyncio` + `respx`, `uv`.

**Spec:** [`docs/superpowers/specs/2026-05-26-v0.9.0-bounded-fanout-design.md`](../specs/2026-05-26-v0.9.0-bounded-fanout-design.md).

**Branch:** `feat/v0.9.0-bounded-fanout` (already created from `main`, spec already committed as `3e43302`).

**TDD shape:** Task 1 is pure config (no test). Task 2 writes the two failing tests up front. Task 3 implements the helper + wraps the gathers, making the tests pass. Task 4 ships.

# ─── v0.9.0: bounded GH fan-out ──────────────────────────────────────


class FakeGitHubClient:
    """Minimal GitHubClient stand-in for the bounded-fanout tests.

    Instruments every GH-touching method with a current/max in-flight
    counter. A tiny `asyncio.sleep` forces real concurrency — without
    it, fast coros could resolve sequentially and the cap assertion
    would pass vacuously.
    """

    def __init__(self, *, repo_count: int) -> None:
        self.repo_count = repo_count
        self.current_in_flight = 0
        self.max_in_flight = 0
        self.total_calls = 0

    async def _enter(self) -> None:
        self.total_calls += 1
        self.current_in_flight += 1
        self.max_in_flight = max(self.max_in_flight, self.current_in_flight)
        # Force genuine concurrency by yielding to the event loop.
        await asyncio.sleep(0.005)

    def _exit(self) -> None:
        self.current_in_flight -= 1

    async def get_user(self, login: str) -> dict[str, object]:
        await self._enter()
        try:
            return {
                "login": login,
                "type": "User",
                "bio": None,
                "followers": 0,
                "public_repos": self.repo_count,
                "created_at": "2020-01-01T00:00:00Z",
                "company": None,
                "blog": None,
                "hireable": False,
            }
        finally:
            self._exit()

    async def list_repos(self, login: str) -> list[dict[str, object]]:
        await self._enter()
        try:
            return [
                {
                    "name": f"repo-{i}",
                    "full_name": f"{login}/repo-{i}",
