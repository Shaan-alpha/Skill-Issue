# v1.0.1 "Launch Ops" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Human-gated tasks:** Tasks 4–8 are OPERATOR tasks — they require Shaan's accounts (GitHub Education, get.tech, Vercel dashboard, Sentry org, DigitalOcean). An agent presents the checklist, waits, then runs only the marked verification probes. Do not attempt to perform operator steps.

**Goal:** Clear the launch blockers with GitHub Education perks — production domain skillissue.tech, Sentry Session Replay + raised trace sampling, and the 100 RPS load test — then release v1.0.1.

**Architecture:** One small deploy-safe PR (shared `siteOrigin()` helper consumed by metadata/OG/card code + Sentry client replay config), followed by an operator cutover (domain, env, OAuth callback, load test), finished by a release task (README hosts, CHANGELOG, version literals, tag) behind a pause gate.

**Tech Stack:** Next.js 16 (App Router, `"use client"` init file), `@sentry/nextjs` v10, vitest, FastAPI backend (env-only change), Vercel domains/env, DigitalOcean droplet + Docker + SRH for the load test.

**Spec:** [`docs/superpowers/specs/2026-07-10-github-education-upgrades-design.md`](../specs/2026-07-10-github-education-upgrades-design.md) §3.

## Global Constraints

- No `Co-Authored-By:` trailers; no "Generated with" footers (AGENTS.md rule 2).
- Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`).
- CHANGELOG entries are user-facing prose (they become the public GitHub Release body).
- Replay privacy: masking stays **default-on** (`maskAllText` / `maskAllInputs` / `blockAllMedia` all default `true`) — the v0.8.0 PII contract applies to replays too. Never pass options that weaken it.
- Trace sampling starts at **0.2** (spec §3.2); env-tunable, retune after a week of launch data.
- Frontend note (`frontend/AGENTS.md`): this Next.js version has breaking changes — check `node_modules/next/dist/docs/` before using unfamiliar Next APIs. (This plan touches no Next-specific APIs beyond `metadataBase`.)
- All frontend commands run from `frontend/`; expect the suite to grow from 58 passing tests.
- Version literals live in FOUR places and must stay in lockstep: `frontend/package.json`, `frontend/src/lib/site.ts` (`APP_VERSION`), `backend/pyproject.toml`, `backend/app/settings.py` (`VERSION`).

```ts
// Canonical site origin. Prod sets NEXT_PUBLIC_SITE_URL; the fallback is the
// production domain so metadata/OG URLs never point at a preview host.
export function siteOrigin(): string {
  const fromEnv = process.env.NEXT_PUBLIC_SITE_URL?.replace(/\/$/, "");
  if (fromEnv) return fromEnv;
  return "https://skillissue.tech";
}

export function siteHost(): string {
  return siteOrigin().replace(/^https?:\/\//, "");
}
```
