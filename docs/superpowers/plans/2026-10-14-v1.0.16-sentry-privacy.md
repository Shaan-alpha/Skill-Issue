# v1.0.16 Privacy Patch (Sentry and PostHog) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the PII contract and the privacy page true on the SDKs we run today. No cookie, session id, token, app secret, IP, geolocation header, OAuth value or request body may reach Sentry, and PostHog may not store visitor IPs or record sessions.

**Architecture:** Both apps declare one contract: a header allow-list, query-parameter deny terms, extra keys and the literal `[Filtered]`. A drift test holds the two sides equal.
- **Collected at the source:**
  - Frontend: an explicit `dataCollection` constant, plus `httpIntegration` with no body capture on the Node server.
  - Backend: `include_local_variables=False` and `max_request_body_size="never"`.
- **Enforced after:** one scrubber per app runs on errors and transactions alike. It fails closed: an unreadable part is dropped, never sent.
- **Canary tests prove it end to end:** the backend through the real app, the frontend through the SDK's own request pipeline. A local envelope smoke repeats the check for each real server.

**Tech Stack:** `@sentry/nextjs` 10.76.2 with `@sentry/core` 10.76.2 (Next.js 16.4, Vitest 4, TypeScript 5.9); `sentry-sdk[fastapi]` 2.72.0 (FastAPI, Python 3.12, pytest, httpx); `posthog-js`; uv; npm.

**Spec:** [`docs/superpowers/specs/2026-10-14-v1.0.16-sentry-privacy-design.md`](../specs/2026-10-14-v1.0.16-sentry-privacy-design.md)

## Global Constraints

- **The contract lists,** spelled the same way in both apps:
  - `HEADER_ALLOWLIST` = `user-agent, referer, content-type, accept, host`. Exact names, compared case-insensitively.
  - `QUERY_DENY_TERMS` = `code, state, token, key, secret, session, sid, passw, pwd, credential, csrf, xsrf, jwt, bearer`. Substring match on the parameter name, lowercased.
  - `SCRUB_EXTRA_KEYS` = `access_token, access_token_ct, oauth_state, oauth_code, session_id, email`.
  - `FILTERED` = `[Filtered]` (literal; never URL-encoded).
- **No SDK upgrades.** Stay on `@sentry/nextjs` 10.76.2 and `sentry-sdk` 2.72.0. Sentry 11 is v1.0.18.
- **The backend's Sentry init stays opt-out only.** It never passes `send_default_pii` or `data_collection`; in 2.72 the latter turns on permissive defaults and drops the EventScrubber.
- **The scrubbers never raise.** Every rule runs in its own guard, and a part that is the wrong type, or whose rule throws, is deleted.
- **No visible change** except the privacy page's cookie list, and no score change.
- **Canary values are fake** and live only in tests and the local smoke. Never print or paste real secrets, tokens or DSNs.
- **Commit messages** follow the repo's house style, with no AI attribution lines or trailers of any kind.
- **Verification by type of change:**
  - Run the `verify` skill (Chrome at 1440/1024/768/390) before committing the one rendered change (Task 7, the privacy page), and once more over the whole branch before the PR.
  - Backend changes are proven by pytest against Postgres.
  - Frontend changes are proven by lint, tsc, Vitest and `next build`.

## Review Focus

1. **Header names in any case, and values that are arrays** (`Cookie`, `USER-AGENT`, a repeated header as a list). Only allow-listed names survive, case-insensitively, and the rest go. Tests: Task 1 `test_header_names_are_matched_in_any_case`, Task 5 `"matches header names in any case"`.
2. **URL edge cases:** a query with a fragment, a parameter without `=`, a URL ending in `?`, and a `referer` that is itself a URL with secrets. Sensitive values become `[Filtered]` and everything else is untouched. Tests: Task 1 `test_url_edge_cases_are_left_intact`, Task 5 `"leaves URL edge cases intact"`.
3. **Already-encoded values** (`code=a%2Fb`) and the backend's percent-decoded query string. The sensitive value is filtered whole, and safe parameters stay byte-for-byte. Tests: Task 1 `test_encoded_values_are_filtered_whole`, Task 5 `"filters already-encoded values whole"`.
4. **One unreadable part among good ones** (a bad `request` beside good `contexts`). Only the bad part is dropped, and the rest of the event is still scrubbed and sent. Tests: Task 1 `test_one_bad_part_does_not_cost_the_rest`, Task 5 `"drops only the part it cannot read"`.
5. **A request with no query string or no headers at all,** the common case. The event passes through with its other fields unchanged. Tests: Task 1 `test_an_event_without_request_details_is_unchanged`, Task 5 `"leaves an event without request details unchanged"`.

```python
"""Sentry init + PII scrub hook for the FastAPI backend.

The PII contract lives in docs/OBSERVABILITY.md ("PII contract"). Scrubbing
happens in `scrub_event`, which runs on errors (`before_send`) and on
transactions (`before_send_transaction`). The contract lists mirror
frontend/src/observability/scrub.ts; tests/observability/test_scrub_drift.py
fails if the two diverge.
"""

from __future__ import annotations

import logging
from typing import TYPE_CHECKING, Any

import sentry_sdk
from sentry_sdk.integrations import DidNotEnable, Integration
from sentry_sdk.integrations.asyncpg import AsyncPGIntegration
from sentry_sdk.integrations.fastapi import FastApiIntegration
from sentry_sdk.integrations.httpx import HttpxIntegration
from sentry_sdk.integrations.logging import LoggingIntegration

if TYPE_CHECKING:
    from collections.abc import Callable

# Request headers that may reach Sentry; every other header is dropped.
_HEADER_ALLOWLIST = ["user-agent", "referer", "content-type", "accept", "host"]
# A query parameter whose name contains one of these keeps its name, and its
# value becomes [Filtered]: OAuth code and state, tokens, keys, sessions.
_QUERY_DENY_TERMS = [
    "code",
    "state",
    "token",
    "key",
    "secret",
    "session",
    "sid",
    "passw",
    "pwd",
    "credential",
    "csrf",
    "xsrf",
    "jwt",
    "bearer",
]
_FILTERED = "[Filtered]"

# Header-like keys dropped wherever they appear in `extra` and `contexts`
# (request headers themselves go through the allow-list above).
_SCRUB_HEADER_NAMES = {
    "cookie",
    "set-cookie",
    "authorization",
    "x-vercel-id",
    "x-internal-secret",
    "x-revalidate-secret",
    "x-client-ip",
    "x-forwarded-for",
    "x-real-ip",
}
_SCRUB_EXTRA_KEYS = {
    "access_token",
    "access_token_ct",
    "oauth_state",
    "oauth_code",
    "session_id",
    "email",
}

_ALLOWED_HEADERS = frozenset(_HEADER_ALLOWLIST)
# Span attributes carry headers as http.request.header.user_agent and so on.
_ALLOWED_SPAN_HEADER_KEYS = frozenset(
    f"http.{direction}.header.{name.replace('-', '_')}"
    for direction in ("request", "response")
    for name in _HEADER_ALLOWLIST
)
_URL_DATA_KEYS = frozenset({"http.target", "http.url", "url.full", "url"})
_QUERY_DATA_KEYS = frozenset({"url.query", "http.query"})


def _sensitive_param(name: str) -> bool:
    lowered = name.lower()
    return any(term in lowered for term in _QUERY_DENY_TERMS)


def _filter_query(query: str) -> str:
    """Blank the values of sensitive parameters. A plain split, never URL
    encoding, so the result matches the frontend's byte for byte."""
    prefix = "?" if query.startswith("?") else ""
    pairs = []
    for pair in query[len(prefix) :].split("&"):
        name, sep, _value = pair.partition("=")
        pairs.append(f"{name}={_FILTERED}" if sep and _sensitive_param(name) else pair)
    return prefix + "&".join(pairs)


def _filter_url(url: str) -> str:
    """Filter the query part of a URL or path; the rest is untouched."""
    base, sep, rest = url.partition("?")
    if not sep:
        return url
    query, hash_sep, fragment = rest.partition("#")
    return f"{base}?{_filter_query(query)}{hash_sep}{fragment}"


def _replace(owner: dict[str, Any], key: str, scrub: Callable[[Any], Any]) -> None:
    """Replace owner[key] with its scrubbed value, or drop it if scrubbing
    fails. Fails closed: a part we can't read is a part we don't send. The
    hook itself must never raise, because the SDK would drop the whole event,
    alert events included."""
    if key not in owner:
        return
    try:
        owner[key] = scrub(owner[key])
    except Exception:
        owner.pop(key, None)


def _allowed_headers(headers: Any) -> dict[str, Any]:
    if not isinstance(headers, dict):
        raise TypeError("request headers")
    out: dict[str, Any] = {}
    for name, value in headers.items():
        lowered = str(name).lower()
        if lowered not in _ALLOWED_HEADERS:
            continue
        out[name] = _filter_url(value) if lowered == "referer" and isinstance(value, str) else value
    return out


def _filtered_query_string(value: Any) -> Any:
    if isinstance(value, str):
        return _filter_query(value)
    if isinstance(value, dict):
        return {k: _FILTERED if _sensitive_param(str(k)) else v for k, v in value.items()}
    if isinstance(value, list):
        return [
            [pair[0], _FILTERED]
            if isinstance(pair, list | tuple) and len(pair) == 2 and _sensitive_param(str(pair[0]))
            else pair
            for pair in value
        ]
    raise TypeError("query_string")


def _filtered_url_value(value: Any) -> str:
    if not isinstance(value, str):
        raise TypeError("url")
    return _filter_url(value)


def _scrub_request(request: Any) -> dict[str, Any]:
    if not isinstance(request, dict):
        raise TypeError("request")
    for key in ("cookies", "data", "env"):
        request.pop(key, None)
    _replace(request, "headers", _allowed_headers)
    _replace(request, "query_string", _filtered_query_string)
    _replace(request, "url", _filtered_url_value)
    return request


def _scrub_user(user: Any) -> dict[str, Any]:
    if not isinstance(user, dict):
        raise TypeError("user")
    user.pop("ip_address", None)
    user.pop("email", None)
    return user


def _scrubbed_span_data(data: Any) -> dict[str, Any]:
    if not isinstance(data, dict):
        raise TypeError("span data")
    out: dict[str, Any] = {}
    for key, value in data.items():
        if key.startswith(("http.request.header.", "http.response.header.")):
            if key in _ALLOWED_SPAN_HEADER_KEYS:
                referer = key.endswith(".referer") and isinstance(value, str)
                out[key] = _filter_url(value) if referer else value
        elif key == "http.request.body.data":
            continue
        elif key in _URL_DATA_KEYS and isinstance(value, str):
            out[key] = _filter_url(value)
        elif key in _QUERY_DATA_KEYS and isinstance(value, str):
            out[key] = _filter_query(value)
        else:
            out[key] = value
    return out


def _scrub_dict_recursive(value: Any) -> Any:
    if isinstance(value, dict):
        return {
            k: _scrub_dict_recursive(v)
            for k, v in value.items()
            if k not in _SCRUB_EXTRA_KEYS and k.lower() not in _SCRUB_HEADER_NAMES
        }
    if isinstance(value, list):
        return [_scrub_dict_recursive(v) for v in value]
    return value


def _scrub_contexts(contexts: Any) -> dict[str, Any]:
    if not isinstance(contexts, dict):
        raise TypeError("contexts")
    trace = contexts.get("trace")
    if isinstance(trace, dict):
        _replace(trace, "data", _scrubbed_span_data)
    return _scrub_dict_recursive(contexts)


def _scrub_spans(spans: Any) -> list[Any]:
    if not isinstance(spans, list):
        raise TypeError("spans")
    for span in spans:
        if isinstance(span, dict):
            _replace(span, "data", _scrubbed_span_data)
    return spans


def _scrubbed_breadcrumb_data(data: Any) -> dict[str, Any]:
    if not isinstance(data, dict):
        raise TypeError("breadcrumb data")
    for key in ("url", "from", "to"):
        if isinstance(data.get(key), str):
            data[key] = _filter_url(data[key])
    if isinstance(data.get("http.query"), str):
        data["http.query"] = _filter_query(data["http.query"])
    return data


def _scrub_breadcrumbs(breadcrumbs: Any) -> Any:
    # Serialized events hold {"values": [...]}; accept a bare list too.
    values = breadcrumbs.get("values") if isinstance(breadcrumbs, dict) else breadcrumbs
    if not isinstance(values, list):
        raise TypeError("breadcrumbs")
    for crumb in values:
        if isinstance(crumb, dict):
            _replace(crumb, "data", _scrubbed_breadcrumb_data)
    return breadcrumbs


def scrub_event(event: dict[str, Any], _hint: dict[str, Any]) -> dict[str, Any]:
    """`before_send` and `before_send_transaction`: enforces the PII contract
    on every error and transaction. Each part is scrubbed on its own and
    dropped if it can't be."""
    _replace(event, "request", _scrub_request)
    _replace(event, "user", _scrub_user)
    _replace(event, "contexts", _scrub_contexts)
    _replace(event, "spans", _scrub_spans)
    _replace(event, "breadcrumbs", _scrub_breadcrumbs)
    _replace(event, "extra", _scrub_dict_recursive)
    return event
```

```ts
/**
 * The Sentry privacy contract (docs/OBSERVABILITY.md, "PII contract"),
 * shared by the browser, server and edge inits.
 *
 * The backend mirrors these lists in app/observability/sentry.py, and
 * backend/tests/observability/test_scrub_drift.py fails if they diverge.
 * Keep each list a flat array of string literals so that test can parse it.
 */

// Request headers that may reach Sentry; every other header is dropped.
export const HEADER_ALLOWLIST = ["user-agent", "referer", "content-type", "accept", "host"];

// A query parameter whose name contains one of these keeps its name, and its
// value becomes [Filtered]: OAuth code and state, tokens, keys, sessions.
export const QUERY_DENY_TERMS = [
  "code",
  "state",
  "token",
  "key",
  "secret",
  "session",
  "sid",
  "passw",
  "pwd",
  "credential",
  "csrf",
  "xsrf",
  "jwt",
  "bearer",
];

// Keys removed from `extra` and `contexts` wherever they appear.
export const SCRUB_EXTRA_KEYS = [
  "access_token",
  "access_token_ct",
  "oauth_state",
  "oauth_code",
  "session_id",
  "email",
];

export const FILTERED = "[Filtered]";

// Not re-exported by @sentry/nextjs, so read it off init's options.
type DataCollection = NonNullable<Parameters<typeof Sentry.init>[0]["dataCollection"]>;

/**
 * What the SDK collects at the source, in every runtime. It replaces
 * sendDefaultPii, whose `false` still let RequestData attach raw cookies.
 * It also governs the request headers 10.x copies onto server spans.
 */
export const SENTRY_DATA_COLLECTION: DataCollection = {
  userInfo: false,
  cookies: false,
  httpHeaders: {
    request: { allow: HEADER_ALLOWLIST },
    response: { allow: HEADER_ALLOWLIST },
  },
  httpBodies: [],
  urlQueryParams: { deny: QUERY_DENY_TERMS },
  graphQL: { document: false, variables: false },
  genAI: { inputs: false, outputs: false },
  databaseQueryData: false,
  stackFrameVariables: false,
};

type Bag = Record<string, unknown>;

const ALLOWED_HEADERS = new Set(HEADER_ALLOWLIST);
const EXTRA_KEYS = new Set(SCRUB_EXTRA_KEYS);
// Span attributes carry headers as http.request.header.user_agent and so on.
const ALLOWED_SPAN_HEADER_KEYS = new Set(
  ["request", "response"].flatMap((direction) =>
    HEADER_ALLOWLIST.map((name) => `http.${direction}.header.${name.replace(/-/g, "_")}`),
  ),
);
const URL_DATA_KEYS = new Set(["http.target", "http.url", "url.full", "url"]);
const QUERY_DATA_KEYS = new Set(["url.query", "http.query"]);

function isBag(value: unknown): value is Bag {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

function isSensitiveParam(name: string): boolean {
  const lower = name.toLowerCase();
  return QUERY_DENY_TERMS.some((term) => lower.includes(term));
}

/**
 * Blanks the values of sensitive parameters. A plain split, never URL
 * encoding, so the result matches the backend's byte for byte.
 */
export function filterQuery(query: string): string {
  const prefix = query.startsWith("?") ? "?" : "";
  const pairs = query
    .slice(prefix.length)
    .split("&")
    .map((pair) => {
      const eq = pair.indexOf("=");
      return eq !== -1 && isSensitiveParam(pair.slice(0, eq)) ? `${pair.slice(0, eq)}=${FILTERED}` : pair;
    });
  return prefix + pairs.join("&");
}

/** Filters the query part of a URL or path; the rest is untouched. */
export function filterUrl(url: string): string {
  const q = url.indexOf("?");
  if (q === -1) return url;
  const hash = url.indexOf("#", q);
  const end = hash === -1 ? url.length : hash;
  return `${url.slice(0, q + 1)}${filterQuery(url.slice(q + 1, end))}${url.slice(end)}`;
}

/**
 * Replaces owner[key] with its scrubbed value, or drops it if scrubbing
 * throws. Fails closed: a part we can't read is a part we don't send. The
 * hook itself must never throw, because the SDK would drop the whole event.
 */
function replace(owner: Bag, key: string, scrub: (value: unknown) => unknown): void {
  if (!(key in owner)) return;
  try {
    owner[key] = scrub(owner[key]);
  } catch {
    delete owner[key];
  }
}

function allowedHeaders(headers: unknown): Bag {
  if (!isBag(headers)) throw new TypeError("request headers");
  const out: Bag = {};
  for (const [name, value] of Object.entries(headers)) {
    const lower = name.toLowerCase();
    if (!ALLOWED_HEADERS.has(lower)) continue;
    out[name] = lower === "referer" && typeof value === "string" ? filterUrl(value) : value;
  }
  return out;
}

function filteredQueryString(value: unknown): unknown {
  if (typeof value === "string") return filterQuery(value);
  if (Array.isArray(value)) {
    return value.map((pair) =>
      Array.isArray(pair) && pair.length === 2 && typeof pair[0] === "string" && isSensitiveParam(pair[0])
        ? [pair[0], FILTERED]
        : pair,
    );
  }
  if (isBag(value)) {
    return Object.fromEntries(
      Object.entries(value).map(([name, v]) => [name, isSensitiveParam(name) ? FILTERED : v]),
    );
  }
  throw new TypeError("query_string");
}

function filteredUrlValue(value: unknown): string {
  if (typeof value !== "string") throw new TypeError("url");
  return filterUrl(value);
}

function scrubRequest(request: unknown): Bag {
  if (!isBag(request)) throw new TypeError("request");
  delete request.cookies;
  delete request.data;
  delete request.env;
  replace(request, "headers", allowedHeaders);
  replace(request, "query_string", filteredQueryString);
  replace(request, "url", filteredUrlValue);
  return request;
}

function scrubUser(user: unknown): Bag {
  if (!isBag(user)) throw new TypeError("user");
  delete user.ip_address;
  delete user.email;
  return user;
}

function scrubbedSpanData(data: unknown): Bag {
  if (!isBag(data)) throw new TypeError("span data");
  const out: Bag = {};
  for (const [key, value] of Object.entries(data)) {
    if (key.startsWith("http.request.header.") || key.startsWith("http.response.header.")) {
      if (ALLOWED_SPAN_HEADER_KEYS.has(key)) {
        out[key] = key.endsWith(".referer") && typeof value === "string" ? filterUrl(value) : value;
      }
    } else if (key === "http.request.body.data") {
      continue;
    } else if (URL_DATA_KEYS.has(key) && typeof value === "string") {
      out[key] = filterUrl(value);
    } else if (QUERY_DATA_KEYS.has(key) && typeof value === "string") {
      out[key] = filterQuery(value);
    } else {
      out[key] = value;
    }
  }
  return out;
}

export function scrubObject<T>(value: T): T {
  if (value === null || typeof value !== "object") return value;
  if (Array.isArray(value)) return value.map(scrubObject) as unknown as T;
  const out: Bag = {};
  for (const [k, v] of Object.entries(value as Bag)) {
    if (EXTRA_KEYS.has(k)) continue;
    out[k] = scrubObject(v);
  }
  return out as unknown as T;
}

function scrubContexts(contexts: unknown): Bag {
  if (!isBag(contexts)) throw new TypeError("contexts");
  if (isBag(contexts.trace)) replace(contexts.trace, "data", scrubbedSpanData);
  if (isBag(contexts.nextjs)) replace(contexts.nextjs, "request_path", filteredUrlValue);
  return scrubObject(contexts);
}

function scrubSpans(spans: unknown): unknown[] {
  if (!Array.isArray(spans)) throw new TypeError("spans");
  for (const span of spans) if (isBag(span)) replace(span, "data", scrubbedSpanData);
  return spans;
}

function scrubbedBreadcrumbData(data: unknown): Bag {
  if (!isBag(data)) throw new TypeError("breadcrumb data");
  for (const key of ["url", "from", "to"]) {
    const value = data[key];
    if (typeof value === "string") data[key] = filterUrl(value);
  }
  return data;
}

function scrubBreadcrumbs(breadcrumbs: unknown): unknown[] {
  if (!Array.isArray(breadcrumbs)) throw new TypeError("breadcrumbs");
  for (const crumb of breadcrumbs) if (isBag(crumb)) replace(crumb, "data", scrubbedBreadcrumbData);
  return breadcrumbs;
}

/**
 * `beforeSend` and `beforeSendTransaction` for every runtime: enforces the
 * PII contract on errors and transactions alike.
 */
export function scrubEvent<T extends Sentry.Event>(event: T): T {
  const bag = event as unknown as Bag;
  replace(bag, "request", scrubRequest);
  replace(bag, "user", scrubUser);
  replace(bag, "contexts", scrubContexts);
  replace(bag, "spans", scrubSpans);
  replace(bag, "breadcrumbs", scrubBreadcrumbs);
  replace(bag, "extra", scrubObject);
  return event;
}
```

```python
DSN for the app: http://public@127.0.0.1:9998/1

from __future__ import annotations

import argparse
import gzip
import itertools
import json
import sys
import zlib
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path

_ITEM_HEADER_KEYS = {"type", "length", "content_type", "filename", "attachment_type", "item_count"}


def decode_body(body: bytes, encoding: str | None) -> bytes:
    """The envelope as the SDK built it, before content encoding."""
    if encoding in (None, "", "identity"):
        return body
    if encoding == "gzip":
        return gzip.decompress(body)
    if encoding == "deflate":
        return zlib.decompress(body)
    raise ValueError(f"unsupported content encoding: {encoding}")


def find_canaries(envelope: bytes, canaries: list[str]) -> list[str]:
    """The canaries that appear anywhere in an envelope."""
    return [canary for canary in canaries if canary.encode() in envelope]


def item_types(envelope: bytes) -> list[str]:
    """The item types in an envelope, read from its item headers."""
    types: list[str] = []
    for line in envelope.split(b"\n"):
        try:
            header = json.loads(line)
        except ValueError:
            continue
        if isinstance(header, dict) and "type" in header and set(header) <= _ITEM_HEADER_KEYS:
            types.append(str(header["type"]))
    return types


def serve(port: int, out: Path) -> None:
    out.mkdir(parents=True, exist_ok=True)
    counter = itertools.count(1)

    class Handler(BaseHTTPRequestHandler):
        def do_POST(self) -> None:
            body = self.rfile.read(int(self.headers.get("Content-Length", "0")))
            envelope = decode_body(body, self.headers.get("Content-Encoding"))
            (out / f"{next(counter):04d}.envelope").write_bytes(envelope)
            self.send_response(200)
            self.send_header("Content-Type", "application/json")
            self.end_headers()
            self.wfile.write(b"{}")

        def log_message(self, *_args: object) -> None:
            return

    ThreadingHTTPServer(("127.0.0.1", port), Handler).serve_forever()


def check(out: Path, canaries: list[str], require: list[str]) -> int:
    seen: set[str] = set()
    leaked = False
    for path in sorted(out.glob("*.envelope")):
        envelope = path.read_bytes()
        types = item_types(envelope)
        seen.update(types)
        found = find_canaries(envelope, canaries)
        print(f"{path.name}: {', '.join(types) or 'no items'}; canaries: {found or 'none'}")
        leaked = leaked or bool(found)
    missing = [kind for kind in require if kind not in seen]
    if missing:
        print(f"missing item types: {missing}")
    return 1 if leaked or missing else 0


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__.split("\n", 1)[0])
    commands = parser.add_subparsers(dest="command", required=True)
    serve_cmd = commands.add_parser("serve")
    serve_cmd.add_argument("--port", type=int, default=9998)
    serve_cmd.add_argument("--out", type=Path, default=Path(".envelopes"))
    check_cmd = commands.add_parser("check")
    check_cmd.add_argument("out", type=Path)
    check_cmd.add_argument("canaries", nargs="+")
    check_cmd.add_argument("--require", nargs="*", default=[])
    args = parser.parse_args()
    if args.command == "serve":
        serve(args.port, args.out)
        return 0
    return check(args.out, args.canaries, args.require)


if __name__ == "__main__":
    sys.exit(main())
```
